East End

Your private house hunt. It opens with your access code.

First, put it on your home screen

  1. Tap the Share button in Safari.
  2. Choose Add to Home Screen, then Add.
  3. Open East End from your home screen and paste your code there.

The home screen app keeps its own storage, so a code pasted here in Safari would not carry over.

How do I get a code?
  1. Open the link below in Safari, signed in to GitHub.
  2. Under Repository access choose Only select repositories and pick east-end-notebook.
  3. Tap Generate token and copy it.
  4. Come back here and paste it above.
Create the code on GitHub

The code opens your notebook and nothing else. It is kept on this phone only. You can cancel it on GitHub at any time.
