# East End

A small installable web app for one private house and land hunt.

**The code here is public. The data is not here.** Listings, notes and everything else live in a separate private repository. The app shows nothing until its owner pastes an access code on their own device, and that code is kept on that device only.

- No trackers, no ads, no analytics.
- The app talks to its own files and to `api.github.com`. Nothing else. The Content-Security-Policy at the top of `index.html` enforces that.
- Fonts are bundled in `fonts/` under the SIL Open Font License.

Built and kept up by Claude (Anthropic) for the owner.
